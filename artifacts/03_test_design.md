# Артефакт 03. Тест-модель для Test IT (ArtCase MVP)

Выполнено по скиллу `test_design.md` по бэклогу `02_task_design.md` (QG-2: PASS).

## Структура Test IT

- **Проект**: ArtCase
- **Разделы дерева кейсов**: Создание арта · Загрузка изображения · Лента · Карточка · Лайк · Поиск по тегу · Удаление · Просмотр изображения
- **Тест-план «MVP — приёмка»**: 8 наборов по разделам; конфигурация — «стенд ArtCase + мобильный клиент»
- **Интеграция с Jira**: кейсы связаны с задачами `ART-N` (для трассировки REQ→TASK→TEST)

Общие предусловия стенда: backend запущен (`mvn spring-boot:run`), приложение установлено; тестовые данные создаются через API перед кейсом, если не указано иное (БД in-memory — OS-6: после рестарта стенда данные пересоздаются). Приоритет в Test IT: High / Medium / Low (Highest бэклога → High).
