# Артефакт 03. Тест-модель для TestRail (ArtCase MVP)

Выполнено по скиллу `test_design.md` по бэклогу `02_task_design.md` (QG-2: PASS).

## Структура TestRail

**Suite**: ArtCase MVP
**Sections**: Создание арта · Загрузка изображения · Лента · Карточка · Лайк · Поиск по тегу · Удаление · Просмотр изображения

Общие предусловия стенда: backend запущен (`mvn spring-boot:run`), приложение установлено; тестовые данные создаются через API перед кейсом, если не указано иное (БД in-memory — OS-6: после рестарта стенда данные пересоздаются).
