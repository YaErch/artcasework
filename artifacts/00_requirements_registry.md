# Артефакт 00. Реестр требований ArtCase

Источник: Confluence `ARTCASE`, «ArtCase — Техническое задание» v2.0 (as-is). Сформирован агентом на этапе 0.

## Функциональные требования (раздел 1.2 ТЗ)

| ID | Требование | Механизм backend |
|---|---|---|
| FR-1 | Создание арта: название (обязательно), описание, теги | POST /arts |
| FR-2 | Загрузка изображения к созданному арту | POST /arts/{id}/image |
| FR-3 | Лента всех артов | GET /arts |
| FR-4 | Карточка арта по идентификатору | GET /arts/{id} |
| FR-5 | Лайк: каждое нажатие +1 | POST /arts/{id}/like |
| FR-6 | Поиск по тегу (вхождение подстроки) | GET /arts/search?tag= |
| FR-7 | Удаление арта | DELETE /arts/{id} |
| FR-8 | Просмотр изображения арта | GET /images/** |

## Требования к данным (раздел 2.2 ТЗ)

| ID | Требование |
|---|---|
| DR-1 | id — число, автоинкремент, генерируется СУБД |
| DR-2 | title — строка до 255, NOT NULL |
| DR-3 | description — строка до 255, необязательное |
| DR-4 | tags — одна строка до 255, свободный формат |
| DR-5 | image_url — null при создании; заполняется после загрузки файла |
| DR-6 | likes — число, по умолчанию 0 |
| DR-7 | Схема создаётся автоматически при старте (ddl-auto=update) |
| DR-8 | СУБД in-memory: данные исчезают при перезапуске; файлы изображений остаются |

## Требования API (раздел 2.3 ТЗ)

| ID | Требование |
|---|---|
| API-1 | GET /arts — 200, массив всех записей; ~30% запросов возвращает 500 (случайная ошибка, заложена в коде) |
| API-2 | POST /arts — 200, созданный объект; imageUrl из запроса игнорируется (null); валидации нет |
| API-3 | GET /arts/{id} — 200 объект; если не найден — 200 с пустым телом (null) |
| API-4 | POST /arts/{id}/like — 200, likes+1; если не найден — 200 с пустым телом; инкремент не атомарен |
| API-5 | POST /arts/{id}/image — multipart (поле file); файл сохраняется как {время}_{оригинальное имя}; если арта нет — 500 |
| API-6 | GET /arts/search?tag= — 200, вхождение подстроки в tags; без параметра tag — 400 |
| API-7 | DELETE /arts/{id} — 200 пустое тело; если не найден — 500 |
| API-8 | GET /images/** — 200 файл; если не найден — 404 |

## Особенности реализации (раздел 3 ТЗ) — ограничения и источники тест-кейсов

OS-1 случайная ошибка ленты ~30% · OS-2 null вместо 404 · OS-3 путь зашит C:/artcase-images/ · OS-4 нет валидации · OS-5 файл без проверки типа/размера · OS-6 БД в памяти · OS-7 нет пагинации · OS-8 нет единой обработки ошибок · OS-9 неатомарный инкремент лайков · OS-10 теги одной строкой · OS-11 файл не удаляется с артом · OS-12 DELETE: 200/500 · OS-13 нет редактирования · OS-14 нет дат · OS-15 H2-консоль включена · OS-16 объединённые строки конфига · OS-17 нет авторизации · OS-18 нет автотестов
