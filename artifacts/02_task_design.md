## Stories

### ART-1. Создание арта
- **User Story**: Как автор, я хочу создать арт (название, описание, теги), чтобы опубликовать свою работу в галерее.
- **Приоритет**: Highest | **Оценка**: 3 SP
- **Трассировка**: FR-1, API-2, DR-2…DR-5 | **Допущения**: A-2
- **AC**:
  - AC1 (позитивный): Given я на форме создания, When я заполняю название (1–255 символов), при желании описание и теги, и нажимаю «Сохранить», Then арт публикуется, в карточке likes = 0, изображение отсутствует (заглушка), imageUrl в данных = null.
  - AC2 (негативный): Given я на форме создания, When поле названия пустое, Then кнопка «Сохранить» неактивна / выводится ошибка «Название обязательно», запрос на сервер не отправляется.
  - AC3 (граничный): When название/описание/теги длиной ровно 255 символов, Then арт успешно создаётся; When 256 символов, Then клиент блокирует ввод сверх лимита с подсказкой (A-2: сервер валидации не имеет, OS-4).

### ART-2. Загрузка изображения
- **User Story**: Как автор, я хочу прикрепить изображение к созданному арту, чтобы работа отображалась в галерее.
- **Приоритет**: High | **Оценка**: 5 SP
- **Трассировка**: FR-2, API-5, API-8, OS-3, OS-5 | **Допущения**: A-5, A-6
- **AC**:
  - AC1 (позитивный): Given существует мой арт без изображения, When я выбираю файл-изображение и загружаю, Then в карточке арта отображается загруженное изображение по ссылке вида /images/{файл}.
  - AC2 (негативный): Given арта с указанным id не существует, When я пытаюсь загрузить файл, Then клиент показывает ошибку «Арт недоступен» (сервер: 500, A-6).
  - AC3 (негативный): When я выбираю файл недопустимого типа (например, .txt) или слишком большой, Then клиент предупреждает и не отправляет файл (A-6: сервер ограничений не имеет, OS-5).
  - AC4 (граничный): When имя файла содержит кириллицу/пробелы, Then файл загружается и доступен по ссылке (A-5).

### ART-3. Лента артов
- **User Story**: Как посетитель галереи, я хочу видеть ленту всех артов, чтобы выбирать работы для просмотра.
- **Приоритет**: Highest | **Оценка**: 3 SP
- **Трассировка**: FR-3, API-1, OS-1, OS-7 | **Допущения**: A-1
- **AC**:
  - AC1 (позитивный): Given в галерее есть арты, When я открываю приложение, Then отображается лента всех артов с названием, описанием, тегами и счётчиком лайков.
  - AC2 (негативный): Given запрос ленты вернул ошибку сервера (500, вероятность ~30%, OS-1), When ошибка получена, Then приложение автоматически повторяет запрос и лента отображается без сообщения об ошибке пользователю (A-1).
  - AC3 (граничный): Given база стенда пуста (после перезапуска, OS-6), When я открываю ленту, Then отображается пустое состояние «В галерее пока нет работ», без ошибки.

### ART-4. Карточка арта
- **User Story**: Как посетитель галереи, я хочу открыть карточку конкретного арта, чтобы посмотреть работу целиком.
- **Приоритет**: Highest | **Оценка**: 2 SP
- **Трассировка**: FR-4, API-3, OS-2 | **Допущения**: A-4
- **AC**:
  - AC1 (позитивный): Given арт существует, When я открываю его из ленты, Then карточка показывает все поля: название, описание, теги, изображение, счётчик лайков.
  - AC2 (негативный): Given арт не найден (сервер вернул 200 с пустым телом, OS-2), When я открываю карточку, Then клиент показывает «Арт недоступен» и выполняется возврат к ленте (A-4).

### ART-5. Лайк арта
- **User Story**: Как посетитель, я хочу отметить понравившуюся работу лайком, чтобы поддержать автора.
- **Приоритет**: High | **Оценка**: 2 SP
- **Трассировка**: FR-5, API-4, DR-6, OS-2, OS-9 | **Допущения**: A-4
- **AC**:
  - AC1 (позитивный): Given я в карточке арта, When я нажимаю «Нравится», Then счётчик увеличивается на 1 и новое значение отображается сразу.
  - AC2 (негативный): Given арт не найден (200 с пустым телом, OS-2), When я нажимаю «Нравится», Then клиент показывает «Арт недоступен», счётчик не меняется (A-4).
  - AC3 (граничный): When я нажимаю «Нравится» повторно N раз подряд, Then счётчик каждый раз увеличивается на 1 (ограничений в as-is нет).

### ART-6. Поиск по тегу
- **User Story**: Как посетитель, я хочу найти работы по тегу, чтобы быстрее находить интересное.
- **Приоритет**: High | **Оценка**: 3 SP
- **Трассировка**: FR-6, API-6, DR-4, OS-10 | **Допущения**: A-3
- **AC**:
  - AC1 (позитивный): Given существуют арты с тегом «city», When я ищу «city», Then отображаются все арты, содержащие этот тег.
  - AC2 (негативный): When запрос пуст (параметр tag не передан), Then клиент не отправляет запрос / требует ввод (сервер вернул бы 400).
  - AC3 (граничный): When я ищу «cit» (часть тега) или тег в другом регистре, Then поиск ведётся по вхождению подстроки, регистр важен (A-3, as-is); по отсутствующему тегу — «Ничего не найдено».

### ART-7. Удаление арта
- **User Story**: Как автор, я хочу удалить свой арт, чтобы убрать неактуальную работу.
- **Приоритет**: Medium | **Оценка**: 2 SP
- **Трассировка**: FR-7, API-7, OS-11, OS-12 | **Допущения**: —
- **AC**:
  - AC1 (позитивный): Given существует мой арт, When я подтверждаю удаление, Then арт исчезает из ленты и поиска, карточка недоступна («Арт недоступен»).
  - AC2 (негативный): Given арт уже удалён, When выполняется повторное удаление, Then клиент корректно обрабатывает ошибку сервера (500, OS-12) без «успешного» сообщения.

### ART-8. Просмотр изображения
- **User Story**: Как посетитель, я хочу видеть изображение работы в полном размере, чтобы рассмотреть детали.
- **Приоритет**: Medium | **Оценка**: 2 SP
- **Трассировка**: FR-8, API-8, DR-5 | **Допущения**: —
- **AC**:
  - AC1 (позитивный): Given у арта загружено изображение, When я открываю просмотр, Then изображение загружается по ссылке /images/{файл} и отображается полностью.
  - AC2 (негативный): Given файл изображения недоступен (прямая ссылка вернула 404), When запрашивается просмотр, Then клиент показывает заглушку «Изображение недоступно».
  - AC3 (граничный): Given арт создан без изображения (DR-5: imageUrl = null), When я открываю карточку, Then отображается заглушка «Нет изображения» вместо ошибки.
